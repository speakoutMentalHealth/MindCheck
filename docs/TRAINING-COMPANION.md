# Training companion

Each existing lesson has a prepared explanation and a local practice question with fixed feedback. Practice does not mark lessons reviewed, change exam results, issue certificates, or persist grades. All five original lessons and the official assessment handoff remain unchanged.

Optional Gemini explanations are available for listening, boundaries, minimal notes and respectful communication. Only an allowlisted public topic identifier, English language and adult confirmation are transmitted. No DOM lesson extraction, learner answers, progress, free text, names or private case information is sent. The safety/immediate-danger lesson is excluded from AI; its summary points learners to the original teaching and responsible human procedure. This is an English companion to the existing English course.

The shared server knowledge base contains four trainingOnly topics, excluded from the general guide topic cards. Provider instructions and output safeguards remain unchanged. Public AI explanations are cached in memory for this visit only, avoiding repeat calls. Page loads and lesson changes do not call AI. New lesson selection aborts pending work and ignores stale replies. Text is rendered with textContent and prepared explanations remain available offline/on failure. The existing free-provider disclosure is shown before an AI request.

Validation covers exact payloads, no automatic requests, local feedback without progress/assessment changes, repeat-call caching, safety exclusion, failures, and the existing five-width training course and light/night accessibility checks. A separate server deployment must pin this source before claiming the new topics generate successfully; tests with mocked responses alone do not prove production generation.
